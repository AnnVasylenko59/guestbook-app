# Лабораторна робота 2. Трирівнева архітектура (Guestbook App)

Багатомодульний вебзастосунок на базі Maven, що реалізує трирівневу (гексагональну) архітектуру з використанням Java, Servlet API, JDBC (H2) та автоматичним контролем архітектури через ArchUnit.

## Архітектура проєкту
Проєкт розділено на три модулі:
- **`core`** — доменні моделі (`Book`, `Comment`), типи пагінації (`Page`), порти (`CatalogRepositoryPort`, `CommentRepositoryPort`) та бізнес-логіка (валідація, бізнес-правило видалення відгуку протягом 24 годин).
- **`persistence`** — реалізація портів доступу до даних через JDBC та вбудовану базу даних H2.
- **`web`** — вебрівень на базі Servlet API, HTTP-контракти (JSON), логування (SLF4J/Logback) та ArchUnit тести.

## Технології
- **Java 21**
- **Apache Maven** (багатомодульна збірка)
- **Jetty 11** (сервер застосунку)
- **H2 Database** (файлова БД)
- **ArchUnit** (архітектурне тестування)
- **Jackson** (JSON мапінг)
- **SLF4J / Logback** (логування)
