# Лабораторна робота №6: Шаблонізація у Spring MVC з використанням Thymeleaf

## 📌 Мета роботи
Ознайомитися з принципами серверного рендерингу у Spring MVC за допомогою шаблонізатора Thymeleaf. Навчитися створювати динамічні HTML-сторінки на основі даних із контролерів, реалізовувати зв’язування форм із моделлю (form binding), використовувати умовні елементи, фрагменти (layout) та забезпечувати локалізацію інтерфейсу користувача.

---

## 🛠 Технології та стек
* **Java 21**
* **Spring Boot / Spring MVC 3.3.4**
* **Thymeleaf** (серверний шаблонізатор)
* **H2 Database** (розподілене сховище даних через JDBC)
* **Maven** (багатомодульний проєкт: `core`, `persistence`, `web`)

---

## 📂 Структура проєкту
Архітектура побудована за принципами чистої архітектури та поділена на три Maven-модулі. Усі зміни в цій лабораторній роботі стосуються виключно рівня `web`:

| Модуль | Призначення | Зміни в ЛР №6 |
| :--- | :--- | :--- |
| **`core`** | Бізнес-логіка, доменні моделі (`Book`, `Comment`), порти та сервіси. | *Без змін* |
| **`persistence`** | JDBC-реалізація репозиторіїв та робота з БД. | *Без змін* |
| **`web`** | Контролери, конфігурація та веб-інтерфейс. | Інтегровано `Thymeleaf`, створено HTML-шаблони, додано підтримку i18n та видалено застарілі JSP. |

---

## 🚀 Виконані завдання

1. **Підготовка середовища:**
   * Додано залежність `spring-boot-starter-thymeleaf` у файл `web/pom.xml`.
   * Створено структуру каталогів для шаблонів `src/main/resources/templates/` та статичних ресурсів `src/main/resources/static/css/`.

2. **Оновлення контролерів:**
   * Переписано REST-контролери на MVC-контролери (`BooksController`, `CommentsController`), які повертають назви шаблонів (`return "books"`) та передають дані через об'єкт `Model`.
   * Реалізовано обробку методів для додавання нових книг (`GET /books/new` та `POST /books`).

3. **Створення шаблонів Thymeleaf:**
   * **`books.html`** — відображення каталогу книг із використанням циклу `th:each` та умовних операторів `th:if` / `th:unless` для обробки порожнього стану («Книг поки немає»).
   * **`book-add.html`** — форма додавання нової книги з двостороннім зв'язуванням через `th:object` та `th:field`.

4. **Локалізація інтерфейсу (i18n):**
   * Створено файли ресурсів `messages.properties` (українська за замовчуванням), `messages_en.properties` (англійська) та `messages_fr.properties` (французька).
   * Налаштовано `CookieLocaleResolver` та `LocaleChangeInterceptor` для динамічного перемикання мови інтерфейсу за допомогою параметру `?lang=uk` / `?lang=en` / `?lang=fr`.

5. **Використання фрагментів (Layout):**
   * Спільні елементи інтерфейсу (навігація, заголовок) винесено у фрагмент `fragments/header.html` та підключено на сторінках за допомогою директиви `th:replace`.

---

## 🖥 Перевірка роботи та посилання
* **Перегляд каталогу книг:** `http://localhost:8080/books`
* **Форма додавання книги:** `http://localhost:8080/books/new`
* **Перемикання мов:** Додавання параметру до URL, наприклад: `?lang=en` або `?lang=fr`.
